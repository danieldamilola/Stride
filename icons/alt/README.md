# Alternate ring study

These are unused alternates for the Umber mark. They were drawn procedurally to test
optical sizes: wider bands at small sizes, a rough bark edge, a pith dot and a thin
fissure. The shipped icon set comes from `icons/logo` and `icons/dev`.

Files:

- `dark-512.png`: dark neutral tile
- `light-512.png`: light neutral tile
- `dev-dark-512.png`: dark violet dev tile
- `dev-light-512.png`: light violet dev tile

Nothing in the project references this folder.
