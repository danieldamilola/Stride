# Release Note: v1.2.3

* **Tab Tearing**: Drag a tab away from the strip to open it in another window. Drop it onto another Stride tab strip to dock it. The tab keeps its loaded page, JavaScript state, unsaved form input, running timers and navigation history across the move. Tearing the last tab in a window moves that window instead of opening a new one. With the floating command bar on, WebView2 builds a torn-off tab's page surface against the window it started in and cannot move it, so that tab reloads when you close the window it was torn off from instead of going blank.
* **Centered Pinned Tab Favicons**: Pinned tabs now render as 32 DIP wide squarcles with favicons centered horizontally and vertically. Removed asymmetrical left column margins and extra empty star space on pinned cards.
* **Pinned Tab Drag And Drop Partitioning**: Pinned tabs now reorder exclusively within the pinned tab range, and unpinned tabs reorder exclusively within the unpinned tab range. Pinned drag ghosts render as compact 32 DIP squarcles with centered icons instead of wide text pills. Pinning moves the tab to the end of the pinned group, and unpinning returns it to the start of the unpinned group.
* **Standard Tab Design**: Tabs are now unified into standard cards across Stride. Removed compact icon-only mode in favor of full tab cards with site favicon, clean title, and hover close buttons.
* **Helium Tab Card Styling**: Tabs render as detached squarcle cards with 8px corner radii, 31px height, standard 190 DIP width, and equal share shrinking across the viewport. The close button now displays exclusively on hover across all tabs with a 4px rounded-rectangle highlight.
* **Helium Toolbar Alignment And Element Spacing**: Toolbar height refined to 38 DIP, with standard 28 DIP location bar height, 28x28 DIP toolbar action and navigation buttons, 6 DIP section dividers, and 3 DIP element padding matching Helium's 3 DIP base spacing system.
* **Suggestions That Start With Your History**: The address bar dropdown now blends visited pages first, then shortcuts, then web phrases. Local matches render instantly and web results append without rebuilding the list, so the flicker is gone. Turning off search suggestions now actually stops the network calls.
* **Standard Suggestion Rows**: Dropdown rows now show a per-type icon plus the page title and domain instead of one clock icon and raw URLs. Arrow keys fill the box with the highlighted row, Up from the top row and Esc restore what you typed, and Enter opens the highlighted target.
* **Suggestion Favicons And Cleaner Rows**: Rows now show the site favicon resolved from the cache, falling back to the type icon while it loads. Repeat visits sharing a page title collapse to one row. The green accent bar on the active row is gone.
* **Domain Only Address Bar**: The bar shows the bare domain instead of the full URL. Focusing it reveals the full address for editing or copying, and Enter on the untouched display reloads the page. Internal pages name themselves instead of showing blank: Search, Downloads, Settings, History, and the rest.
* **One Dropdown At A Time**: The floating command bar list now uses the same rich rows as the toolbar, and the toolbar popup stays shut while the floating panel is open. The floating bar is off by default for new profiles.
* **Type Instantly On New Tabs**: Landing on a new tab focuses the bar with everything selected. Clicking an unfocused bar selects all instead of dropping a caret, so there is no backspacing first.
* **Plus Follows The Last Tab**: The new tab button now sits right behind the last tab instead of trailing the address bar.
* **Pinned Tabs Stay Icon Only**: Pinned tabs never show a title or any close button, in compact and Full Names modes alike, and keep their narrow icon width instead of stretching with the strip.
* **Restore Lands On Your Last Tab**: Restarting with session restore now opens the tab you closed on, not the first tab. Sessions saved before this change still open on the first tab.
* **Extensions Settings Section**: Ad and tracker blocking, YouTube Enhancer and YouTube Unhook now sit together in a new Extensions section instead of being split across Privacy & Security and YouTube. Everything that changes what the browser does to a page is in one place. YouTube Enhancer and YouTube Unhook collapse so a 20-toggle group is not a wall of switches, and each one shows how many of its own settings are on while collapsed.
* **Taskbar Icon Sharpness**: Rebuilt stride.ico and stride-light.ico from the 1024 masters with the full Windows size set 16, 20, 24, 32, 40, 48, 64, 96, 128, 256 so the taskbar finds a native 24px entry at 100 percent DPI instead of scaling the nearest size. Both ICOs are now embedded as resources.
* **No Dots Truncation**: Removed ellipsis trimming across tab titles, URL label, suggestion lists, link preview, drag ghost, and context menu preview so clipped text ends clean with no dots. The URL label now uses MaxWidth 200 instead of a fixed 80 width.
* **Tab Drag Reorder**: Tabs can now be reorganised by dragging. A solid pill with the tab favicon and title follows the cursor, edge zones auto scroll overflowing strips, and the drop commits the new order. Cancelling restores the start slot.
* **Full Names Shrink To Fit**: Full Names mode now shares the strip width across every tab, capped at full card width. Opening more tabs shrinks every card so all tabs stay visible with no scrolling. Titles collapse to favicons on tiny cards, and the close button moves from the card end to the favicon overlay as cards shrink. Compact mode is unchanged.
* **Tab Strip Stays Inside The Window**: The strip no longer grows past the space it is given. Tabs shrink from full card width toward favicon width and only scroll once even favicons stop fitting. Full Names mode dropped its fixed 120 DIP floor and gives up titles for the whole strip once one title per tab stops fitting, and the default favicon mode now shrinks the same way instead of holding 32 DIP pills. Thirty tabs on a 1920 window fit end to end, against about five wide cards before.
* **Close Button Is Clickable Before It Appears**: The close slot stays live at zero opacity instead of leaving layout, so the end of every wide tab closes on click the way Helium does, with the cross fading in on hover and staying lit on the active tab. Narrow tabs still hand the job to the favicon overlay.
* **Favicon Tabs Need A Click Before The Cross**: A crowded tab that has shrunk to a bare favicon no longer offers close on hover. The cross appears only once the tab is selected, so a stray hover across a packed strip cannot close a tab you never chose.
* **Tab Titles Fade Instead Of Cutting**: Titles lose their ellipsis and soften out through a gradient mask, so a clipped title ends in a fade rather than three dots. Short titles are untouched because the mask sits past the text.
* **Tab Search Removed**: The magnifier button and its popup are gone along with the Ctrl+Shift+A binding and the controller behind them. The toolbar keeps its downloads, reader and settings actions.
* **Window Resize Floor Raised**: Minimum window size is now 760 by 480, matching the width where the toolbar already collapses its centre dock into a second row. The browser stops shrinking before the layout has to squeeze.
* **Toolbar Stops Leaving A Dead Gap**: The tab strip used to arrange itself at the width its own tabs asked for, so a 12 tab strip in a 935 DIP toolbar took 456 and left the rest empty around the plus button. The list now takes every DIP the toolbar hands over, so cards expand to fill and the plus sits at the end of the strip.
* **Address Bar Hugs Its Content**: The standard bar used to claim a fixed 38 percent of the toolbar with a 120 DIP floor, so a short or empty URL still reserved a wide hollow pill. It now starts at 90 DIP, grows to its content and caps at the old maximum, so a bare new tab page no longer carries a long empty box.
* **Reload And Address Bar Sit Tight**: The margin between the nav buttons and the address bar was 16 DIP split across three containers, which read as a large hole on a sparse toolbar. The URL domain grouping lost its left margin and the address bar its left margin, halving the gap to 8 DIP on both sides of the bar.
* **Address Bar Starts On The Left**: A new profile now puts the address bar on the left and leaves the floating command bar off. Both were the wrong way round for a first run, so every new user started with the bar on the right. Existing profiles are untouched.
* **Force Dark Mode Moved To Extensions**: The setting now sits at the top of the Extensions section instead of down in Theme, where it looked like an app appearance choice. It is not an extension underneath: it runs on Chromium's own dark engine through a browser argument, so this is about where it lives rather than how it works.
* **Enter Closes The Suggestions**: Pressing Enter shut the dropdown, but the suggestion fetch started when you typed was still running. When it landed it reopened the list over the page you had just navigated to. Closing the list now cancels that fetch, so Enter, Escape and picking a row all leave the dropdown shut.
* **Suggestion Rows Lead With The Page Name**: A visited page row already led with the page title and put the domain beside it in the dimmer second text. Search phrase rows did not. Every phrase row repeated the label DuckDuckGo Search, which took enough width to trim the phrase itself down to a few letters, so the rows all looked identical and unreadable. The phrase is now the whole row, and the list is exactly as wide as the address bar with no floor under it.
* **Inline Ghost Autocomplete Removed**: Typing used to fill the top suggestion into the box and leave the remainder selected. That ghost fought the caret, because Backspace deleted it and the next suggestion pass put it straight back, so the box looked frozen the moment the dropdown appeared. The ghost is gone from the toolbar bar, the floating command bar, and every other address entry, along with the state machine and the completion rules behind it. The dropdown stays exactly as it was. Arrow keys still fill the box with the highlighted row, Up from the top row and Esc still hand back what you typed, and Backspace or Delete on a highlighted row still gives you your query back before it edits anything.
* **Adaptive Toolbar Color**: New Layout toggle. On keeps today's behavior, tinting the toolbar with the active site theme. Off keeps the neutral toolbar on every site.
* **New Skull App Icon**: New dark and light skull mark across the window icon, taskbar, installer, and tab fallback favicon, with resized sets and a rebuilt multi resolution ICO. Dark skull shows by default and the light skull follows the light theme.
* **Rounded App Tile**: The app icon is now a rounded skull tile in every theme. stride-tile is the single 1024 master for the whole codebase. stride.ico and stride-light.ico were rebuilt from it with the full Windows size set, and every fallback PNG set was regenerated from the same art, so the taskbar, Start menu, window chrome, tab favicons, and installer all show one consistent tile. The legacy masters are deleted.

**Changes**
* **YouTube Unhook Restored**: The element-hiding features are back, covering the feed, watch page, player, and interface, with every feature in the settings list now working.
* **YouTube Hide Shorts Rewritten**: The previous version hid any item section containing a Shorts shelf, and YouTube wraps ordinary feed videos in item sections too, so real feed content disappeared along with the shelf and the page lost its scroll height. Hiding Shorts now matches YouTube's own shorts marker on the shelf and limits every structural test to a direct-child relationship, so it cannot reach content it was not aimed at. The Shorts shelf, individual Shorts in the feed grid, the left navigation entries, the channel tab and the search chip are all covered.
* **YouTube Sidebar Toggles Merged**: Hide video sidebar and Hide recommended videos are now one toggle. The old pair made no sense together. Hide recommended videos emptied the sidebar but left the column, so the video stayed narrow beside an empty black strip, and hiding the video sidebar made the first one pointless. One toggle now removes the column, and the video takes the full width. An existing Hide recommended videos setting still works and now hides the whole column.
* **YouTube Sidebar No Longer Blocks Scrolling**: The previous Hide video sidebar removed the ceiling on the player column, so the player sized itself to the full window width and reserved matching vertical space. In theater mode the player is pinned to the top of the scroller, so the description fell below the fold with no scroll range left to reach it and the wheel did nothing. The column is now hidden and YouTube's own width variable zeroed, which reclaims the space without touching the player's sizing.
* **YouTube Enhancer And Ad Skipper Parked**: The playback quality and speed preferences and the ad skipper stay switched off, so YouTube behaves exactly as YouTube intends. The scripts are parked rather than deleted, and the settings that controlled them stay in place so they can come back. Wallhaven downloads, theme colours, link preview and uBlock are unaffected.
* **Smaller Download**: Removed code that was no longer used. Dark Reader was still embedded in every build even though Force Dark Mode runs on Chromium's own dark mode flag, which accounts for most of the size. A leftover temporary extraction folder, an unused constant, several empty methods and duplicate log lines are gone.

**Bug Fixes**
* **Torn-Off Tab Died With Its Old Window**: WebView2 keeps each control tied to the window it was created in and tears it down when that window closes, so a tab moved to another window went blank as soon as the window it came from shut. The control now follows its tab to the window showing it. Unsubscribing from a dead page no longer aborts the rest of the teardown and take the browser down with it.
* **Download Closes Browser**: Fixed the browser shutting itself when starting a download. Download landing pages call window.close once the file starts, and the WebView2 control answers that by closing the whole host window, not just the tab. Stride now detaches that built-in handler when wiring each tab, so only the tab closes and the download keeps running. The download handler also guards every native read, posts store updates without blocking, and falls back to the URL or a default file name when the native path is missing. Proven by stride.log showing WebView2's own window-close handler on the shutdown stack.
* **Taskbar Grouping And Start Icon**: Shortcuts created by the installer now carry AppUserModelID Stride to match the running process so pinned taskbar buttons group with the open window instead of opening a second button. The installer and the micro updater now notify the shell after install so the Start menu picks up the new skull icon without a manual cache clear. Stride also verifies its Start menu and taskbar shortcuts on every launch and stamps the missing AppUserModelID in place, then notifies the shell when anything changed.

# Release Note: v1.2.2

**Features**

# Release Note: v1.2.0 Native Seamless Updater

**Features**
* **Native Seamless Updates**: The update flow has been completely redesigned. A native gear in a tray icon appears on your toolbar when an update is available. Clicking it shows a real-time circular progress ring while it downloads in the background, followed by a green checkmark to install.
* **Invisible Micro-Updater**: When you click the green checkmark, Stride swaps files behind the scenes using a new invisible Windows GUI executable updater, eliminating wizard dialogs, UAC prompts, and NetSparkle dependencies.
* **Reader Mode**: Press Ctrl+Shift+R on any article to switch it to a clean, distraction-free reading view. Powered by Mozilla Readability, scripts are disabled while reading, and links clicked inside reader exit gracefully back to the live page. The reader mode icon is now a static toolbar button and can be toggled in Settings. The hotkey Ctrl+Shift+R still works anytime.
* **Link Preview**: Hold Alt and click or hover any link to peek at it in an isolated preview window without leaving your current page. Open it in a new tab or your current tab from the preview toolbar, or press Esc to dismiss.
* **Customizable Tab Dim**: New Performance settings let you dim sleeping and hibernated tabs, with independent opacity sliders so you can tune how faded background tabs look.
* **Pinned Tab Resource Controls**: Two new toggles allow pinned tabs to sleep and hibernate like normal tabs when you want maximum memory savings. Off by default, pinned tabs stay fully alive unless you opt in.
* **What's New Page**: Stride now shows a styled release-notes page once after each update, using the same design language as onboarding. It never interrupts first-run setup and remembers what you have seen.
* **Redesigned Settings**: Settings were reorganized into clear sections with a search bar, making it easy to find any option fast.
* **First-Run Onboarding**: A guided welcome flow covers address bar style, privacy defaults, built-in tools, search engine, theme, accent color, and import. It appears only on first launch, never again on every start.
* **Downloads Page Redesign**: Borderless cards with subtle backgrounds match the History page philosophy. White progress bars replace green, and neutral status dots are used. File type icons use Icons8 instead of plain text abbreviations. Completed downloads show only the filename.
* **Popup Dialog Redesign**: All dialog windows now have rounded corners and neutral surface-colored buttons. The bright green accent OK button that clashed with the dark theme has been removed.
* **Dialog Window Positioning**: Dialogs no longer float above all applications. Topmost has been removed so dialogs stay with Stride, and the offset drop shadow has been removed.
* **Dynamic Context Menu**: Rebuilt the right-click menu to be context aware. The top row shows Back, Forward, and Reload. Plain pages show Find in Page and Select All. Editable fields show Undo, Redo, Cut, Copy, and Paste. Links show Open in new tab and Copy link. Images show Save image and Copy image URL. Reader View appears when available. The T&C Lens extension is accessible from the menu. Keyboard shortcuts display for supported actions.
* **Release Notes Auto-Open**: Stride opens internal://releasenotes automatically after an update installs.

**Bug Fixes**
* **Micro-Updater Merge Crash**: Fixed a crash where updates touching existing subdirectories were silently dropped because the updater skipped directories that already existed. The updater now merges directories recursively and validates the package before swapping.
* **Tab Dim Flicker**: Stale suspend callbacks could mark a tab you just switched to as sleeping, re-dimming it during restoration or crash recovery. Suspension generations now invalidate outdated callbacks.
* **Sleep Setting Race**: Disabling Tab Sleep now reliably clears the sleeping state instead of racing with in-flight suspends.
* **Reader Extraction Hang**: Extraction now times out instead of freezing the UI when a page is hibernated or unresponsive.
* **Preview Safety**: Link previews validate window dimensions and suppress stray downloads triggered inside the peek window.
* **Update Pipeline Hardening**: Installer downloads are Ed25519 signature verified against the appcast before anything executes, and the micro updater now validates zip integrity, handles pre-release tags, and uses ArgumentList with retries.
* **Link Preview and Reader Mode**: Alt+Click now displays the link preview window instead of only dimming. The Reader Mode button now successfully activates.
* **Right-Click Menu**: Fixed a COM error that prevented the context menu from rendering. The application now checks for the existence of link, image, or selection data before reading it.
* **Downloads Hang**: Fixed a bug where downloads froze at 100 percent. .NET Garbage Collection dropped native events, and SmartScreen suspended background downloads. SmartScreen is now disabled by default.
* **Download UI Commands**: The Pause, Resume, and Cancel buttons on active downloads now function.
* **Local HTML Files**: Stride now opens local .html files launched from Windows Explorer or the command line. Stride supports being the default offline HTML viewer.
* **New Tab Reloads**: Adding or removing a shortcut updates the UI instantly without reloading the entire New Tab page.
* **New Tab Shortcuts**: Adding a shortcut with special characters or importing bookmarks no longer breaks the New Tab page. Shortcuts are now passed using Base64 encoding.
* **Toolbar Icon Toggles**: Disabling the Show Reader Icon setting instantly removes the icon from the toolbar.

**Under the Hood**
* Removed all NetSparkle dependencies. `UpdateService` now uses `HttpClient` to hit the GitHub REST API and download the zip archive. `build-release.ps1` now outputs both a zip for the micro updater and an exe installer for new users, with atomic zip creation and clean publish.
* Added hardening to the micro updater: recursive directory merge, zip validation for `Stride.exe`, retry and timeout handling for GitHub API including pre-release tags, dynamic version wiring into Inno Setup, self update via pending .new files, and robust process handling with ArgumentList and grace period for WebView2 locks.
* Message handlers moved into the engine layer with a sealed router contract, and WebView2 environment plus IPC ownership extracted into dedicated classes.
* Test suite grew to over 160 unit tests covering navigation policies, router behavior, reader sanitizing, link preview policy, and update verification.
* Extracted URL parsing and command-line argument dispatch into dedicated services, and removed the NetSparkleUpdater WPF row from Settings.
